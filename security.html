Что происходит с твоими данными

Прямые ответы на вопросы, которые задают разработчики перед скачиванием.

Что приложение делает с моими данными?

Всё работает локально. По умолчанию языковая модель загружается прямо в процесс приложения — GGUF-файл лежит у тебя на диске, запросы никуда не уходят.

Серверов Доки не существует — некуда отправлять данные. Это не маркетинговая фраза: у приложения нет бэкенда, нет облака, нет аккаунтов.

Какие данные собираются?

Приложение — никакой телеметрии, аналитики, счётчиков запусков и отчётов о крешах. Дока не отправляет ничего ни при запуске, ни в процессе работы. Проверь в Charles Proxy или Wireshark: наружу не уйдёт ни одного байта, пока ты сам не сделаешь запрос к модели.

Этот сайт — использует Яндекс Метрику. Метрика собирает стандартную веб-аналитику: страницы, источники трафика, клики, записи сессий. Данные обрабатываются по политике Яндекса. Если это неприемлемо — блокируй через uBlock Origin или аналог.

Какие разрешения запрашивает приложение?

Файловая система — только к папке, которую ты явно выбираешь через диалог «Папка агента». Дока не сканирует диск самостоятельно.

Сеть — для обращения к языковой модели.

Браузер — только с твоего явного подтверждения в диалоге. Без согласия браузер не запускается.

Терминал — выполнение команд тоже требует подтверждения в диалоге. Можно запомнить разрешение на текущий сеанс, при следующем запуске снова спросит.

Почему код закрытый?

Коммерческая разработка — это честный ответ.

При этом закрытый код не означает «верь на слово». Все сетевые запросы приложения проверяемы в реальном времени: открой Charles Proxy, Wireshark или встроенный DevTools Electron — увидишь только запросы к выбранному тобой провайдеру моделей.

Можно подключить облачный AI — ChatGPT, Claude, GigaChat?

Да. Дока поддерживает любой OpenAI-совместимый API (OpenAI, Anthropic через прокси, Mistral, локальный Ollama, LM Studio и любой сервер с /chat/completions) и MCP-серверы. Ключ API вводишь ты сам — он хранится на твоём устройстве и передаётся только в момент запроса напрямую к выбранному провайдеру.

Важно про облачные модели: при использовании стороннего API (OpenAI, Anthropic, Сбер и др.) твои запросы и данные обрабатываются по политике конфиденциальности этого провайдера. Дока работает только как интерфейс — данные идут напрямую от тебя к провайдеру, не через какие-либо серверы Доки.

Как проверить самому?

Три инструмента, которые покажут весь трафик приложения:

Charles Proxy — GUI, удобен для macOS и Windows, показывает запросы в реальном времени.

Wireshark — более низкоуровневый, фильтруй по порту или хосту.
